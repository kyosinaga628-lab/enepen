Fear & Greed Index JP

日本市場の温度感を、一目で。
日経平均・TOPIXなど日本独自のデータから、投資家心理を0〜100のスコアで毎日数値化します。

サイトを見る

概要

米国版CNN Fear & Greed Indexの日本市場版。日経平均・TOPIXや日本国債のデータを独自に収集・分析し、 投資家が今「恐怖」を感じているか「貪欲」になっているかを0〜100のスコアで数値化します。 スピードメーター形式のゲージで直感的に相場の温度感を把握できます。

7つの分析指標

  • 市場モメンタム: 日経平均 vs 125日移動平均
  • 株価の強さ: 高値圏銘柄 vs 安値圏銘柄
  • 市場の幅: 騰落レシオ（値上がり数 vs 値下がり数）
  • プット・コール・レシオ: オプション弱気派の割合
  • 市場ボラティリティ: 日経VI（恐怖指数）の推移
  • 安全資産への需要: 株式 vs 国債リターン比較
  • 社債への需要: 投資家のリスク許容度

技術スタック

Python (データ取得) GitHub Actions (毎日自動更新) Chart.js Static HTML / CSS / JS JSON-LD (SEO)
