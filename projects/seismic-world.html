地球の脈動を可視化する。
世界の地震データを、光と音のアニメーションで表現。

世界地図を見る

概要

「SEISMIC WORLD (Global Earthquake Visualization)」は、世界の地震データを可視化するWebアプリケーションです。 Leaflet.jsとCartoDB Dark Matterタイルを使用したダークモードの世界地図上に、 地震の発生を時系列でアニメーション表示します。 円の大きさや色、そしてWeb Audio APIによる音響効果で、地震の規模（マグニチュード）を直感的に感じることができます。

主な機能

  • 地図表示: 視認性の高いダークテーマの世界地図
  • 地震の表現: マグニチュードに応じた円の大きさと色分け（シアン: M4.5+、黄色: M5.0+、赤色: M6.0+）
  • 音声フィードバック: 規模に応じた音の高さと大きさで発生を通知
  • コントロール: 再生速度変更（0.1x〜5.0x）、タイムラインシーク
  • データアーカイブ: 直近1ヶ月、1年、および2011年からの過去データを切り替え可能

技術スタック & データ

HTML5/CSS3 Vanilla JS Leaflet.js Web Audio API Python

データソース: USGS（アメリカ地質調査所）API。マグニチュード4.5以上の地震データを取得・可視化しています。
