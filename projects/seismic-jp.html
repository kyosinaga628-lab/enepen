Seismic JP

大地の鼓動を、光と音で感じる。
2011年から現在までの地震データを、時系列アニメーションで可視化。

可視化デモを見る

概要

日本列島周辺で発生した地震を、CartoDBのダークマップ上に動的にプロットするデータビジュアライゼーション作品です。 マグニチュードの大きさを円のサイズと色で表現し、発生に合わせて音声を生成することで、 視覚と聴覚の両方で地震活動の頻度と規模を体感できます。

主な機能

  • インタラクティブな光のマップ
  • 時系列タイムラプス再生（2011-2025）
  • マグニチュード連動オーディオフィードバック
  • GitHub Actionsによるデータ自動更新
  • USGS Earthquake API連携

技術スタック

Python (Data Fetching) Leaflet.js Web Audio API GitHub Actions
