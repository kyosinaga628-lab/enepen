プライバシーポリシー

制定日: 2026年10月10日

enepen.（以下「当運営者」）は、YouTube チャンネル「【UPDATE】エネルギーの論点」および「知の巨人ラボ」の運営にあたり、動画投稿用の内部ツール「ENEPEN Uploader」（以下「本ツール」）を使用しています。本ポリシーは、本ツールが Google アカウントおよび YouTube のデータをどのように扱うかを定めるものです。

1. 本ツールの利用者

本ツールは、当運営者が自らの YouTube チャンネルを管理するためだけに使用する非公開のツールです。第三者へ提供・公開しておらず、当運営者以外のユーザーのデータを取得することはありません。

2. 取得するデータと利用目的

本ツールは YouTube API サービスを利用し、当運営者の Google アカウントの許可のもとで、次の目的に限ってデータにアクセスします。

  • 当運営者のチャンネルへの動画のアップロード、公開予約、サムネイルの設定
  • 当運営者が投稿した動画のタイトル・説明欄・タグの更新、および削除
  • 当運営者のチャンネル情報と、投稿動画の再生数などの統計の確認

3. データの保存

認証で発行されるトークンは、当運営者の端末内にのみ保存します。YouTube から取得したデータを外部のサーバーへ送信・保存することはありません。

4. 第三者への提供

取得したデータを第三者に販売・提供・共有することはありません。広告目的にも利用しません。

5. Google のポリシーとの関係

本ツールは YouTube API サービスを利用しています。本ツールの利用には YouTube 利用規約 が適用され、データの取り扱いには Google プライバシーポリシー が適用されます。本ツールによる Google API から受け取った情報の使用は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. アクセス許可の取り消し

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

7. お問い合わせ

本ポリシーに関するお問い合わせは enepen789@gmail.com までご連絡ください。
